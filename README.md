# 🔍 Customer Churn Analysis

> Analyzed behavior of 7,043 telecom customers to identify churn patterns using Python

---

## 📌 Project Overview

Customer churn is one of the biggest challenges in the telecom industry. This project analyzes customer behavior to identify key factors that lead to churn and suggests early engagement strategies to retain customers.

---

## 🛠️ Tools & Technologies

- **Python** — Pandas, NumPy, Matplotlib, Seaborn
- **Jupyter Notebook**
- **Dataset** — Telco Customer Churn (7,043 records)

---

## 📊 Key Steps

1. **Data Loading & Exploration** — Loaded dataset and explored structure
2. **Data Cleaning** — Handled missing values, converted data types
3. **EDA** — Analyzed churn patterns by contract, tenure, charges
4. **Visualizations** — Generated 6 charts to highlight churn-prone segments
5. **Key Insights** — Identified actionable recommendations

---

## 📈 Visualizations

| Chart | Description |
|---|---|
| Churn Distribution | Overall churn vs non-churn customers |
| Churn by Contract | Churn rate across contract types |
| Churn by Tenure | How tenure affects churn |
| Monthly Charges | Charges distribution by churn |
| Churn Rate % | Churn rate percentage by contract |
| Correlation Heatmap | Correlation between key variables |

---

## 🔑 Key Findings

- 📌 **38% of churned users** were on monthly contracts with less than 3-month tenure
- 📌 **Month-to-month** contract customers have the highest churn rate
- 📌 Customers with **higher monthly charges** are more likely to churn
- 📌 **Long-term contract** customers have very low churn rates

---

## 💡 Recommendations

- Focus retention efforts on **monthly contract** customers
- Offer **discounts to new customers** in first 3 months
- Promote **long-term contracts** with special incentives
- Implement **early engagement strategies** for high-risk customers
